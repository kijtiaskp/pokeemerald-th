# คู่มือการแปล Pokémon Emerald ภาษาไทย

## รูปแบบไฟล์
- Input: `data/work/<batch>.jsonl` แต่ละบรรทัดคือ `{id, kind, en, maxBytes?, map?, speakers?, usage?}`
- Output: `data/translations/<batch>.jsonl` แต่ละบรรทัดคือ `{"id": "...", "th": "..."}` ครบทุก id ที่ไม่ใช่ `trivial`
- `en`/`th` เป็นข้อความระดับ source: `\n` `\l` `\p` `\"` เป็น escape แบบ backslash จริง (ใน JSON คือ `\\n`)
- ตรวจงานทุกครั้ง: `node --disable-warning=ExperimentalWarning src/validate.ts data/translations/<batch>.jsonl`

## กฎที่ห้ามผิด
1. คง token `{...}` ทุกตัวไว้ครบ จำนวนเท่าเดิม ห้ามแปลชื่อ token (`{PLAYER}` `{STR_VAR_1}` `{RIVAL}` `{KUN}` `{COLOR RED}` `{PAUSE 30}` `{B_ATK_NAME_WITH_PREFIX}` ฯลฯ) ย้ายตำแหน่งได้ตามไวยากรณ์ไทย
2. ถ้า `en` ลงท้ายด้วย `$` ต้องลงท้าย `th` ด้วย `$` และห้ามมี `$` ที่อื่น
3. `kind` = `dialog` / `match_call` / `battle`: ห้ามใส่ `\n` หรือ `\l` เอง ใช้ `\p` แบ่งกล่องข้อความเท่านั้น (ประมาณ 1 กล่อง ≤ 2 บรรทัด × 28 ตัวอักษรไทยฐาน) เครื่องมือจะตัดบรรทัดให้อัตโนมัติ ใส่ช่องว่างระหว่างวลี/ประโยคตามธรรมชาติภาษาไทยเพื่อเป็นจุดตัดบรรทัด
4. kind อื่น (ui, item_desc, dex ฯลฯ): คงโครงสร้าง `\n` ตามต้นฉบับ (จำนวนบรรทัดเท่าเดิม) และทำให้แต่ละบรรทัดสั้นพอ ๆ ต้นฉบับ ข้อความ UI เมนูต้องกระชับที่สุด
5. `maxBytes`: นับ 1 ต่อ 1 ตัวอักษร (สระ/วรรณยุกต์นับ 1, `ำ` นับ 2, ช่องว่างนับ 1) ห้ามเกิน
6. ใช้ได้เฉพาะ: ตัวอักษรไทย (ยกเว้น ฃ ฅ ฦ ฿ และเลขไทย), A-Z a-z 0-9, `! ? . , - … “ ” ‘ ’ ' : ; / ( ) & + = % ♂ ♀ ¥ é` และช่องว่าง ห้ามใช้ `"` ตรง ๆ (ใช้ “ ”)
7. `é` ใน `POKéMON`/`POKé` ของต้นฉบับ แปลเป็นคำไทยตาม glossary ไม่ต้องคง

## ชื่อเฉพาะ
- ใช้ `data/glossary/*.json` เป็นหลักเสมอ ชื่อโปเกมอน ตัวละคร สถานที่ ใช้ชื่อญี่ปุ่นทับศัพท์ไทย (ฟุชิกิดาเนะ, ฮารุกะ, เมืองมิชิโระ)
- ห้ามแปลชื่อที่มีใน glossary แบบอื่น ชื่อที่ไม่มีใน glossary: ทับศัพท์จากชื่อญี่ปุ่นถ้ารู้แน่ ถ้าไม่รู้ ทับศัพท์จากอังกฤษ
- คำศัพท์เกม: โปเกมอน, เทรนเนอร์, ยิม, หัวหน้ายิม, จตุรเทพ, แชมเปี้ยน, เข็มกลัด, มอนสเตอร์บอล, โปเกเด็กซ์, โปเกนาวี, โปเกมอนเซ็นเตอร์, โปเกมาร์ท, ท่า, คุณสมบัติ, ไอเท็ม, เบอร์รี่, คอนเทสต์, ฐานลับ, แก๊งแม็กม่า, แก๊งอควา, บริษัทเดวอน, HP PP Lv คงอักษรละติน

## น้ำเสียงและตัวละคร (สำคัญที่สุด)
งานแปลต้องอ่านเหมือนมนุษย์เขียนบทเกม ไม่ใช่แปลตรงตัว สื่ออารมณ์ มุก และนิสัยตัวละครให้เป็นธรรมชาติแบบภาษาไทย
- ดูผู้พูดจาก `speakers` (gfx sprite, `gender`, trainer class/gender), ชื่อ label, prefix ในข้อความ (`MOM:`, `WALLY:`), map และบรรทัดรอบข้างใน batch เดียวกัน
- คำลงท้ายต้องตรงเพศและระดับภาษา: ผู้ชายสุภาพ `ครับ`, ผู้หญิงสุภาพ `ค่ะ` (บอกเล่า) / `คะ` (คำถาม/เรียกขาน), เป็นกันเอง `นะ` `ล่ะ` `สิ` `เถอะ` `จ้ะ/จ๊ะ` (หญิงอ่อนโยน) `จ้า` `ฮะ` (เด็กชาย) `เว้ย` (ชายห้าว), ห้ามใช้ `กู/มึง`
- สรรพนามตามตัวละคร: ชายสุภาพ `ผม`, หญิงสุภาพ `ดิฉัน`/`ฉัน`, เด็ก `หนู`/`เรา`, คนแก่ `ข้า`/`ลุง`/`ป้า`/`ยาย`/`ตา`, แม่เรียกตัวเอง `แม่` เรียกผู้เล่น `ลูก`, พ่อ (เซ็นริ) `พ่อ`/`ลูก`, ตัวร้าย/หัวหน้าแก๊ง `ข้า`/`ฉัน`, ลูกกระจ๊อกแก๊ง `ฉัน`/`พวกเรา` ห้าว ๆ
- เรียกผู้เล่น: `{PLAYER}`, `เธอ` (เป็นกันเอง), `คุณ` (สุภาพ), `หนู` (ผู้ใหญ่/คนแก่เรียกเด็ก), `ลูก` (พ่อแม่) ห้ามระบุเพศผู้เล่น
- ป้าย/ข้อความระบบ/ไอเท็ม/UI: ภาษาเขียนกลาง ๆ ไม่มีคำลงท้าย
- ความสม่ำเสมอ: ตัวละครเดิมใช้สรรพนาม/คำลงท้ายชุดเดิมตลอด (ดูรายการใน `data/glossary/characters.json` ช่อง `voice`)
- `{KUN}` ในต้นฉบับอังกฤษว่างเปล่า คงไว้ตำแหน่งท้ายชื่อ `{PLAYER}{KUN}`
